# Screenshots

Use the native macOS screenshot tool. The repo-managed `screenshot` configuration
sets `/Users/Shared/Screenshots` as its save location.

## Shortcuts

```bash
cmd + shift + 1 # Maximize Ghostty
cmd + shift + 2 # Maximize Zed
cmd + shift + 3 # Ghostty left, Zed right
cmd + shift + 4 # Zed left, Ghostty right
cmd + shift + 5 # Open native screenshot controls
cmd + shift + h # Open the draggable screenshot shelf
```

Adding `control` copies a capture to the clipboard without creating a file, so
clipboard-only captures do not produce a preview or sync to the VM.
