## How to develop on 2 machines while staying sane

### Branch naming

1. On local machine use branch name `sm`.
2. On VM use branch name `sm2`.

### Merging Prompt changes

1. Do not wait forever to merge prompt changes for agents-subagents.
2. Ideally, wait maximum one day, then merge.
    - Maybe eventually we will have a CI way of checking but we don't have anything right now.
