# ocint ctx History Search Reference

This directory keeps reference material for the `ocint ctx` OpenCode history
search workflow.

`CTX_SKILL.md` is a reference copy of the original `ctx-agent-history-search`
skill. It is intentionally not named `SKILL.md`, so OpenCode does not treat it as
an active skill entrypoint.

Use this material when updating `ocint ctx` guidance or comparing the old `ctx`
workflow with the OpenCode-only `ocint ctx` workflow.
